# 方法理解：先弄清地图上的数值在说什么

这份材料是我们基于课程代码和物种分布模型文献形成的学习解释，不是乔慧捷老师的原话，也不替代脚本中的具体设置。使用任何一种算法前，先把问题说成一句完整的话：**在什么时间、什么空间单元、什么数据范围内，预测哪一种生态状态，并准备用结果做什么？**

## 1. 从出现点到背景点

[D1](../upstream/day-scripts/D1.R)中的出现记录告诉我们“有人在这里记录到了物种”。没记录到的地点可能没调查，也可能调查了却没探测到。[D2](../upstream/day-scripts/D2.R)的背景点因此是环境对照样本，不是经验证的缺失点。背景区域选得太大或太小，模型学到的对照就会变化。这也是为什么“可到达区域”需要生态学上的理由。

## 2. 算法各做了什么

- **BIOCLIM**：用已知出现点的环境范围描述一个轮廓，再看别处的环境与这个轮廓有多相似。适合建立直觉，但轮廓受样本覆盖影响。
- **GLM**：先写出环境变量与响应之间的函数形式，再估计系数。若把背景点写成 0，拟合的是出现点与所抽背景点的对比；不能直接把输出称为真实发生概率。
- **Maxent / `maxnet`**：比较出现点和背景区域的环境分布，允许用不同特征表示弯曲关系，并通过正则化控制复杂度。特征和正则化怎样设，会改变地图的形状。
- **随机森林、GAM 等**：在[D11](../upstream/day-scripts/D11.R)中并列展示不同算法面对新环境的行为。换算法会改变拟合和外推的方式；不会自动解决数据偏差、扩散限制或未来气候的不确定性。

## 3. 一张地图至少有三个不同问题

第一，**它在已观察范围内能否描述记录？** 第二，**它能否预测未参与拟合、但环境相近的地点？** 第三，**它能否转移到新地区或未来？** 这三个问题所需的验证证据不同。高训练拟合或随机交叉验证 AUC，最多支持相应数据划分下的区分能力，不能直接证明跨地区、跨时间可靠。[D6](../upstream/day-scripts/D6.R)、[D12](../upstream/day-scripts/D12.R)正适合比较不同划分带来的差异。

## 4. 分辨率不是准确度

环境栅格的一个像元可能覆盖很大面积。像元大小告诉我们地图有多细，不告诉我们像元内的温度、降水是否准确，更不保证它能表示鸟实际选择的栖息微环境。[D1](../upstream/day-scripts/D1.R)示例下载 `res = 10` 的 WorldClim 数据，即 10 角分；这不是 README Day 0 列举的所有可选分辨率。做局地样线或鸟类声学研究时，应再检查植被、地形、人为活动、季节与探测过程是否处在匹配的尺度。

## 5. 二值图和“范围变化”有额外假设

把连续分值切成“有／无”，必须先定阈值。阈值不同，扩张和收缩面积也可能不同。[D4](../upstream/day-scripts/D4.R)用一个人为改变的气候栅格演示地图代数，适合学习计算流程；真实未来投影还需要合理的情景、环境一致性检查、独立评估和不确定性报告。图上的“新增适宜区”不等于物种必然会扩散到那里。

## 6. 占域模型与课程中的出现点模型

占域模型通常明确区分真实占域状态和“调查了却没探测到”的观测过程。这套课程中的许多示例主要使用出现点与背景点来建模气候关联；它们并没有因为用了鸟类数据就自动变成占域模型。若将被动声学监测数据放进来，需要先决定分析单位、重复调查、检测过程和目标量，再选相应模型。

## 7. 把研究过程交代清楚

我们可用 **ODMAP**（Overview、Data、Model、Assessment、Prediction）检查一个分析是否讲清问题、数据、模型、验证和地图含义。ODMAP 是报告框架，不是新的拟合算法；填完整也不保证模型一定正确。课程代码提供了练习这些判断的材料，正式研究仍需依据具体目标重新审查每个选择。参见 [Zurell 等的原论文](https://doi.org/10.1111/ecog.04960)。
