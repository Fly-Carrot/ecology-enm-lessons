# 学习导航：从生态问题走到模型地图

这份导航是我们对乔慧捷老师课程代码的学习注释。脚本和英文课程提纲来自[原仓库](https://github.com/qiaohj/ENM_curriculum)；这里的分组、解释和提醒由本仓库维护者整理。建议一边看代码，一边问：我们究竟想预测什么？哪些地方真的被调查过？地图要用于哪里？

## 先看一条连续的故事线

假设我们手里有丹顶鹤的出现记录，想知道它与环境的关系，并画一张地图。第一步看似简单：把出现点放在地图上，再把每个点的气候值取出来。[D1.R](../upstream/day-scripts/D1.R)做了这件事。但地图上没有记录的地方，不一定没有丹顶鹤。于是[D2.R](../upstream/day-scripts/D2.R)引入背景点，用 GLM 和 Maxent 比较出现点与背景环境。

模型能画图后，新的问题是：变量是否重复？模型有没有把训练地点记得太牢？[D3.R](../upstream/day-scripts/D3.R)开始筛选变量和评估模型，[D5.R](../upstream/day-scripts/D5.R)调节 Maxent 的复杂度，[D6.R](../upstream/day-scripts/D6.R)比较背景区域和数据划分方式。把模型用于未来或别的地区时，还要面对[D4.R](../upstream/day-scripts/D4.R)与[D11.R](../upstream/day-scripts/D11.R)讨论的转移和外推问题。[D7.R](../upstream/day-scripts/D7.R)、[D9.R](../upstream/day-scripts/D9.R)则让我们在地理空间和环境空间中看模型说了什么。

这一顺序解释了为何课程不只是在教“按下拟合按钮”：每增加一种用途，原先可以暂时搁置的假设就会变得重要。更细的概念解释见[方法理解](方法理解.md)。

## 运行前先看这里

1. **先准备数据，再运行脚本。** 本仓库没有随附 README 中提到的完整 `Data/`、`Figures/`、`Scripts/`、`Output/` 目录。部分示例会联网下载数据，部分需要另行准备本地文件。原 README 中的 `m9.figshare.XXXXXXX` 是占位符，不能作为可用数据链接；课程数据请以发布页面和讲师提供的实际链接为准。
2. **D1–D7 有会话依赖。** 例如 D2 用 D1 创建的 `clim_study_area` 和 `occurrences_clean`；D3–D7 也沿用前面的对象。不要预期逐个打开、从中间某天开始运行就能成功。
3. **检查本机路径。** [D1.R](../upstream/day-scripts/D1.R) 和 [D15.R](../upstream/day-scripts/D15.R) 含有讲师机器上的 `setwd()` 路径；部分专题脚本也假定旧目录层级。D13、D15 还引用仓库外的气候或范围文件。运行前先按[上游代码说明](../upstream/README.md)核对数据和工作目录，不要把课程路径当成通用设置。
4. **先看输出变量的定义。** 例如 Maxent 的连续输出是此分析设置下的适宜性分值；用阈值把它转成二值图，仍需要说明阈值依据和误判代价。
5. **把示范与研究结论分开。** D4 的人为加温、D10 的模拟曲线是帮助理解方法的例子。它们不能单独支撑真实未来分布变化的结论。

这份导航核对了脚本内容和文件结构，但没有把每个脚本当作已在本机完整运行的独立分析。若要复现某一节，建议先锁定那一节的目标、数据版本、包版本、环境栅格、背景范围和输出，再逐项检查。
