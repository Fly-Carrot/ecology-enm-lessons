# 一只丹顶鹤，怎样变成一张分布图？

这门课可以从一个朴素的问题读起：我们知道一些丹顶鹤出现过的地点，能不能据此找到环境相似的地方？一张地图很快就能画出来。接下来的问题更有意思：地图上的颜色究竟代表什么？换一种模型、换一种考法，地图还站得住吗？

乔慧捷老师的课程把这些问题放进了 D1–D15 的代码里。这份中文导读沿着问题往前走；想逐项对照，可随时打开[英文课程提纲](README.md)和相应脚本。我们补充的图来自课程数据的本地复现，图下方都说明了它能回答什么。

想把每一步讲得更细，可以接着读[《一只鸟，一张地图》十二章网页](https://bird-map-ecology-david.robbleeglish.chatgpt.site/)：里面有完整算例、更多分析图，以及占域和现场调查的延伸章节。[网页文件与数据](website/README.md)也已收入这个仓库。

需要对照课堂材料时，可以进入[课程课件 PDF 与逐份导读](course/courseware/README.md)。13 份课件按基础原理、数据与变量、建模工具、评价报告、尺度投影和扩散分为 6 组；每份都说明它在解决什么问题、适合谁看，以及读完能做什么。

## 第一幕：先弄清手里的点

从 GBIF 取得的记录会落在不同的地方，也可能有许多记录挤在同一个气候像元里。D1 先检查坐标能否对应到气候数据，再让每个像元只留一条记录。这样做，是为了减轻重复采样对模型的影响。

![丹顶鹤出现记录如何进入建模数据](docs/figures/story-01-records.png)

这次复现从 **7,239** 条记录开始，**6,323** 条落在有气候值的像元内；按像元去重后，留下 **341** 个建模位置。最后一个数字小了很多，含义却很明确：模型面对的是 341 个不同的气候格子，不是把其余记录简单判作“错”。[查看数据与作图方法](docs/figures/README.md)。

## 第二幕：要找的究竟是哪张地图？

眼前至少有两种不同的任务。一种是描画物种**现在已占据的地方**。另一种是寻找环境上**可能适合、却尚未被占据的地方**。扩散障碍、生物相互作用和调查覆盖，会让这两张图长得不同。乔老师与合作者在[“没有万能算法”](https://doi.org/10.1111/2041-210X.12397)一文中用已知真值的虚拟物种说明：连“画哪张图”都没有说清时，算法排名很难有统一答案（PDF pp. 2–3、6–10）。后来的[理论驱动建模框架](https://doi.org/10.59717/j.xinn-life.2025.100165)进一步把这个问题放在分析开头（PDF pp. 2–6）。

D2 给出现地点找了一组环境对照：从研究范围抽取背景点。背景点告诉模型“这里还有哪些环境可供比较”，并不表示那里确认没有丹顶鹤。随后，GLM 用较平滑的关系描述环境变化，Maxent 可以用不同特征刻画更弯曲的关系。它们都能给地图上的像元打分。

![丹顶鹤 Maxent 示例的连续适宜性地图](docs/figures/story-05-map.png)

这幅图展示 **21,734** 个有效气候像元的连续分数。深色表示在这次模型设置下较高的相对适宜性。要把颜色解释成出现概率，还需要额外的取样与校准条件；这里先把它读作模型的环境比较结果。

## 第三幕：模型会画图，还要看它经不经得起考

D3 让一部分数据暂时离开训练过程，再拿它们评价模型；D5 调节 Maxent 的复杂度。模型越灵活，越能贴近训练点，也越需要检查它有没有把局部细节记得太牢。乔老师的论文没有给出一张“永远选 Maxent”或“永远选随机森林”的榜单：在不同物种、占据情景和目标下，各方法的长处会交换位置（[Qiao 等，2015](https://doi.org/10.1111/2041-210X.12397)，PDF pp. 4–10）。

接下来，D6 把考法也换掉：随机分组、按空间分组，以及改变背景范围。下图比较同一组 Maxent 参数在三套背景与分组方案下的结果。

![同一组参数在三种验证设计下的训练验证差距](docs/figures/story-02-validation.png)

训练与验证 AUC 的平均差距，依次约为 **0.036、0.117、0.157**。这些数字来自同一次课程复现的三个方案。差距变大，提醒我们“在附近找点”和“到另一片地方使用地图”是两种考题。需要去新地区时，验证数据最好也与训练地点分开；[结构化交叉验证研究](https://doi.org/10.1111/ecog.02881)解释了原因与取舍（PDF pp. 1–3、11–15）。

## 第四幕：地图走出熟悉的环境

D7、D9、D13 让我们在两张“纸”上看同一批结果：一张是经纬度地图，另一张以温度、降水等环境条件为坐标。两个地方离得很远，气候也许相近；两个地方挨得近，环境也可能不同。D8 补上栅格、矢量和地图投影这些基础。D10 则把时间与空间的尺子拉开，提醒我们一公里的气候格网和鸟实际经历的微环境并非同一个尺度。

D4 尝试改变环境后再画图。沿着这个问题，我们在复现中另做了一项明确的灵敏度试验：将气候变量 `bio8` 增加 2°C，再按同一阈值给像元分组。

![课堂环境情景下各类像元的面积比例](docs/figures/story-04-scenario.png)

在这个人为设定的情景里，研究范围内约 **17.2%** 的面积进入“新增”一类，约 **7.6%** 落入“原有、情景中未入选”一类。它帮助我们看清模型和阈值会怎样影响地图。D11 再把不同算法放到训练数据之外的温度范围，观察它们各自如何延伸曲线。[乔老师关于模型转移的研究](https://doi.org/10.1111/ecog.03986)正是沿着这个问题继续追问：新地方的环境是否已被训练数据覆盖？（PDF pp. 1、5、7–12）

## 第五幕：换一种数据，问题也跟着变

D14 把回应变量换成鸟类调查中的**计数**，用 `biomod2` 比较六种方法。这个例子拟合的是一个物种的计数数据；六种算法放在一起比较，并不会因此变成联合物种分布模型。

![六种算法在训练期与后一期的评价](docs/figures/story-03-algorithms.png)

图中每种方法都有训练期和后一期的表现。随机森林（RF）的训练期得分很高，到了后一期，两组分数之间出现明显距离。这个例子把“训练时擅长解释数据”和“换时间后仍有用”摆在了同一张图上。D15 又加入专家绘制的分布范围，帮助我们检查出现点、背景和模型地图各自覆盖了哪里。

回头看整门课，顺序就清楚了：**记录给出线索，环境提供对照，模型画出关系，验证决定我们能信它到什么程度。** 选算法前，先说清想回答的问题；图要拿去哪里用，再决定怎样检验它。
