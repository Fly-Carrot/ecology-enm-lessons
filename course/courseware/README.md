## 建议的阅读顺序

第一次接触 SDM，可以先读 D1 → D2 → D3。开始准备自己的研究时，再依次查看 CMT-006、CMT-001、CMT-005。需要 GEE、图形界面、集成模型、尺度、投影或扩散时，进入相应专题即可。

## 01｜基础原理

### D1｜生态位模型的原理与应用（一）

- **课件在回答：** 什么是生态位和物种分布模型，我们怎样从出现记录和环境数据走到一张预测图。
- **主要内容：** Grinnell、Elton 与 Hutchinson 的生态位概念；地理空间与环境空间；BAM 框架；GBIF、IUCN、WorldClim；MaxEnt 入门。
- **适合谁看：** 第一次系统接触 ENM/SDM 的读者。
- **读完能做什么：** 看懂一张分布图是怎样产生的，并知道模型分数不能自动解释成真实出现概率。
- **署名与下载：** 乔慧捷（首页署名）｜[PDF，39 页](01-foundations/D1_ENM-Principles-and-Applications-1.pdf)

### D2｜生态位模型的原理与应用（二）

- **课件在回答：** 为什么“把出现点和环境放进 MaxEnt”还远远不够。
- **主要内容：** 出现记录筛选；MaxEnt 特征和正则化；混淆矩阵、AUC、TSS 与 AICc；算法选择；环境变量和背景点数量。
- **适合谁看：** 已经会跑出第一张地图，准备认真设计模型的人。
- **读完能做什么：** 列出模型设置与评价中必须做出的选择，理解“没有万能模型”的实际含义。
- **署名与下载：** 乔慧捷（首页署名）｜[PDF，26 页](01-foundations/D2_ENM-Principles-and-Applications-2.pdf)

### D3｜生态位模型的原理与应用（三）

- **课件在回答：** 研究问题不同，生态位模型应当怎样进入真实科研工作。
- **主要内容：** SDM 的前沿应用；环境空间的几何表达；气候变化与生物多样性研究案例；模型复杂度与研究目标的匹配。
- **适合谁看：** 想把 SDM 从课堂练习转成论文问题的人。
- **读完能做什么：** 先说清研究目标，再决定模型需要多复杂，以及结果应该支持到哪一层结论。
- **署名与下载：** 乔慧捷（首页署名）｜[PDF，14 页](01-foundations/D3_ENM-Principles-and-Applications-3.pdf)

## 02｜出现数据与环境变量

### CMT-001｜SDM 环境变量

- **课件在回答：** 环境栅格怎样进入 SDM，不同来源的图层怎样放到同一套空间框架里。
- **主要内容：** 栅格结构；裁切、重采样、掩膜和地图代数；WorldClim、CHELSA、遥感和古气候数据；变量相关性；尺度与校准范围。
- **适合谁看：** 正在准备气候、地形、土地覆盖或遥感变量的人。
- **读完能做什么：** 检查 CRS、范围、分辨率、像元原点、单位和时间窗，并根据生态问题选择变量。
- **阅读提示：** “5-8 个变量”和 Pearson `|r| < 0.7` 是经验起点，不是所有研究都适用的固定规则。
- **署名与下载：** Gengping Zhu（首页署名）｜[PDF，41 页](02-data-and-predictors/CMT-001_Variables-for-SDM.pdf)

### CMT-002｜使用 GEE 准备 SDM 环境变量

- **课件在回答：** 不熟悉 JavaScript 时，怎样利用 Google Earth Engine 获取环境数据。
- **主要内容：** GEE 数据目录；QGIS 插件路线；让生成式 AI 起草 GEE Code Editor 脚本；WorldClim 与 Daymet 下载示例。
- **适合谁看：** 想从 GEE 获取大范围或多时段环境变量的初学者。
- **读完能做什么：** 形成一条从数据集检索到导出的路线，并知道还要核对 band、单位、日期、QA、投影和导出分辨率。
- **署名与下载：** Gengping Zhu（首页署名）｜[PDF，12 页](02-data-and-predictors/CMT-002_GEE-Variables-for-SDM.pdf)

### CMT-006｜出现数据与模型策略

- **课件在回答：** 一个出现点是怎样得到的，坐标错误、调查偏差和空间聚集会怎样进入模型。
- **主要内容：** 坐标格式与地理参照；在线数据库和馆藏数据；错误与离群检查；空间 thinning；随机划分、block、checkerboard；稀有物种策略。
- **适合谁看：** 使用 GBIF、公民科学、馆藏或多来源出现记录的人。
- **读完能做什么：** 建立出现记录清洗清单，并根据记录量和部署地点选择数据划分方式。
- **阅读提示：** 原 PDF 封面将 `Occurrence` 拼作 `Occurrance`；本目录使用规范拼法，不改变原课件文件。
- **署名与下载：** ZHU Gengping（PDF 文件元数据；页面未署个人姓名）｜[PDF，36 页](02-data-and-predictors/CMT-006_Occurrence-Data-Model-Strategy.pdf)

## 03｜建模工具与集成模型

### CMT-004｜在 Shiny 中运行 SDM

- **课件在回答：** Wallace、ntbox、`sdm` 等网页或图形界面工具能帮助我们做到什么。
- **主要内容：** R Shiny 的基本思路；Wallace 工作流；ntbox；`sdm` 对象与图形界面；平台的功能边界。
- **适合谁看：** 想先通过界面理解完整流程，再逐步进入 R 脚本的人。
- **读完能做什么：** 选择合适的入门工具，同时知道正式研究仍需保存数据、参数、版本、随机种子和验证设计。
- **署名与下载：** Gengping Zhu（首页署名）｜[PDF，13 页](03-modeling-and-tools/CMT-004_SDM-in-Shiny.pdf)

### CMT-010｜集成模型与小模型集成

- **课件在回答：** 不同算法给出不同地图时怎样汇总；记录很少时怎样控制单个模型的维度。
- **主要内容：** 集成模型的原因与不确定性；GLM、GAM、RF 和 MaxEnt；均值、中位数与加权平均；`biomod2`、`sdm`、`flexsdm`；Ensemble of Small Models。
- **适合谁看：** 需要比较多个算法，或研究稀有种、小样本物种的人。
- **读完能做什么：** 设计一个保留模型分歧的集成方案，并理解集成结果不保证优于最好的单模型。
- **署名与下载：** Gengping Zhu（首页署名）｜[PDF，28 页](03-modeling-and-tools/CMT-010_Ensemble-Model.pdf)

## 04｜评价与透明报告

### CMT-005｜模型阈值与评价

- **课件在回答：** 连续预测怎样变成管理决策，AUC、TSS、partial ROC 和 Boyce 分别说明什么。
- **主要内容：** 空间 block 与 checkerboard；混淆矩阵；MTP、P10 和固定阈值；sensitivity、specificity、TSS、AUC、partial ROC、Boyce；相关 R 包。
- **适合谁看：** 正在选择阈值、评价指标或交叉验证方法的人。
- **读完能做什么：** 把指标与具体任务配对，避免把高 AUC 或随机交叉验证成绩当成跨地区可转移性的证明。
- **阅读提示：** 第 7 页的 Type I / Type II 标签对调；第 20 页阈值 0.5 的 TSS 重算值约为 0.586。实际使用时请以 FP、FN 和公式为准。
- **署名与下载：** Gengping Zhu（首页署名）｜[PDF，38 页](04-evaluation-and-reporting/CMT-005_Model-Threshold-and-Evaluation.pdf)

### D4｜ODMAP 标准报告协议

- **课件在回答：** 一项 SDM 研究需要报告哪些信息，别人才能理解、评价和复现。
- **主要内容：** SDM 报告缺失的常见问题；研究目标、数据、模型拟合、评价和预测五部分；作者、审稿人与编辑的检查责任。
- **适合谁看：** 准备写论文、报告、项目文档或审稿意见的人。
- **读完能做什么：** 用 ODMAP 清单检查数据处理、假设、参数、评价和预测是否交代完整。
- **阅读提示：** PDF 第 1 页标题与副标题有叠字，正文页内容仍可阅读。
- **署名与下载：** Huijie Qiao（PDF 文件元数据；页面未署个人姓名）｜[PDF，6 页](04-evaluation-and-reporting/D4_ODMAP-Protocol.pdf)

## 05｜尺度与地图投影

### Dx｜生态学和进化生物学中的尺度问题

- **课件在回答：** 为什么同一个生态问题换一个空间或时间尺度，结论可能随之改变。
- **主要内容：** 从地球和气候到物种分布的尺度层级；空间异质性；格网大小与生物体尺度；跨尺度推断案例。
- **适合谁看：** 正在决定研究范围、栅格分辨率或外推尺度的人。
- **读完能做什么：** 让数据分辨率、生态过程、物种移动能力和最终使用范围彼此匹配。
- **署名与下载：** 乔慧捷（首页署名）｜[PDF，25 页](05-scale-and-projection/Dx_Scale-in-Ecology-and-Evolution.pdf)

### Dy｜地图投影

- **课件在回答：** 球面上的地点怎样放到平面地图，为什么面积、距离和形状无法同时完全保持。
- **主要内容：** 坐标与投影；经纬度投影；等面积投影；等距离投影；二十面体格网等全球表达方式。
- **适合谁看：** 要计算面积、距离、缓冲区或制作大范围地图的人。
- **读完能做什么：** 根据分析任务选择合适 CRS，避免直接在经纬度上做不合适的距离和面积计算。
- **署名与下载：** 乔慧捷（首页署名）｜[PDF，14 页](05-scale-and-projection/Dy_Map-Projections.pdf)

## 06｜扩散

### dispersalENM｜扩散在 SDM 中的应用

- **课件在回答：** 环境适合并不等于物种能够到达，扩散限制怎样改变未来分布与风险判断。
- **主要内容：** 实际分布与潜在分布；可达区域 M；无扩散、有限扩散和无限扩散情景；环境阻力与方向性驱动；MIGCLIM、megaSDM 和 dispersalENM。
- **适合谁看：** 做气候变化、入侵风险、保护规划或范围变化预测的人。
- **读完能做什么：** 明确写出扩散假设，比较不同扩散情景，并避免把适宜区直接当成未来占据区。
- **署名与下载：** 乔慧捷（首页署名）｜[PDF，9 页](06-dispersal/dispersalENM_Dispersal-in-SDM.pdf)
