# 课程课件

这里集中保存课程使用的演示文稿。13 份课件已获得公开发布许可，并按学习主题分成 6 组。每份课件同时提供两种格式：

- `PPTX`：保留可编辑页面、动画、GIF、视频和讲者备注等原始信息。
- `PDF`：方便直接阅读、检索和引用；一张幻灯片对应一页。

全部课件共 301 页。PPTX 与 PDF 的页数、文件大小和 SHA-256 校验值见 [manifest.csv](manifest.csv)。

## 从哪里开始

| 主题 | 适合解决的问题 | 课件 |
|---|---|---|
| [01 基础原理](01-foundations/) | 生态位是什么、怎样从分布记录走到模型、怎样理解模型边界 | D1、D2、D3 |
| [02 数据与环境变量](02-data-and-predictors/) | 出现记录怎样清理、环境变量从哪里来、GEE 怎样参与数据准备 | CMT-001、CMT-002、CMT-006 |
| [03 建模方法与工具](03-modeling-and-tools/) | 怎样用 Shiny 工具建模、单模型如何组成 ensemble | CMT-004、CMT-010 |
| [04 评价与透明报告](04-evaluation-and-reporting/) | 阈值和评价指标怎样选择、SDM 怎样完整报告 | CMT-005、D4 |
| [05 尺度与地图投影](05-scale-and-projection/) | 研究尺度怎样影响问题、球面世界怎样投到平面地图 | Dx、Dy |
| [06 扩散](06-dispersal/) | 可达区域和扩散能力怎样进入 SDM | dispersalENM |

如果第一次接触 SDM，可以先按 D1 → D2 → D3 阅读，再根据自己的问题进入其余专题。只想快速浏览时优先打开 PDF；准备讲课、检查动画或继续编辑时使用 PPTX。
