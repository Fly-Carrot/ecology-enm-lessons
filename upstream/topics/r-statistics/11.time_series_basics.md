# 11. Time Series Analysis Basics

## 1. Overview
This module introduces the fundamentals of time series: stationarity, sample autocovariance, Sample Autocorrelation Function (ACF), first-order autoregressive AR(1) estimation via Yule-Walker equations, and moving average smoothing.

## 2. Mathematical Formulas
- **Sample Autocovariance at Lag $k$ ($\gamma_k$):**
  $$\gamma_k = \frac{1}{n} \sum_{t=1}^{n-k} (y_t - \bar{y})(y_{t+k} - \bar{y})$$

- **Sample Autocorrelation at Lag $k$ ($\rho_k$):**
  $$\rho_k = \frac{\gamma_k}{\gamma_0} = \frac{\sum_{t=1}^{n-k} (y_t - \bar{y})(y_{t+k} - \bar{y})}{\sum_{t=1}^n (y_t - \bar{y})^2}$$

- **AR(1) Model & Yule-Walker Estimator:**
  $$y_t = \phi y_{t-1} + \epsilon_t \implies \hat{\phi}_{\text{YW}} = \hat{\rho}_1 = \frac{\gamma_1}{\gamma_0}$$

- **Simple Moving Average (Centered Window $2m+1$):**
  $$M_t = \frac{1}{2m + 1} \sum_{j=-m}^m y_{t+j}$$

## 3. Implementation Summary
- Computes sample autocovariance and autocorrelation coefficients vector-by-vector without `acf()`.
- Implements Yule-Walker parameter recovery and rolling smoothing windows.
- Compares against R's built-in `acf(..., plot = FALSE)` and `ar.yw()`.
