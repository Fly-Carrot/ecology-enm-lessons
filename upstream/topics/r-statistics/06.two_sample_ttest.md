# 06. Two-Sample Independent t-Test (Equal & Unequal Variances)

## 1. Overview
This module details independent two-sample hypothesis testing under both homoscedasticity (Pooled $t$-test) and heteroscedasticity (Welch's $t$-test with Satterthwaite approximation for degrees of freedom).

## 2. Mathematical Formulas
- **Student's Pooled Two-Sample $t$-test (Equal Variance $\sigma_1^2 = \sigma_2^2$):**
  $$s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}, \quad t = \frac{\bar{x}_1 - \bar{x}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}, \quad df = n_1 + n_2 - 2$$

- **Welch's $t$-test (Unequal Variance $\sigma_1^2 \ne \sigma_2^2$):**
  $$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$
  $$df_{\text{Welch}} = \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{(s_1^2/n_1)^2}{n_1 - 1} + \frac{(s_2^2/n_2)^2}{n_2 - 1}}$$

## 3. Implementation Summary
- Computes both pooled and Welch $t$-test statistics, Welch fractional degrees of freedom, and two-sided $p$-values.
- Verifies exact matching with `t.test(x, y, var.equal = TRUE)` and `t.test(x, y, var.equal = FALSE)`.
