# 08. Point Estimation & Confidence Interval Construction

## 1. Overview
This module covers point estimators, estimator properties (unbiasedness, efficiency, consistency), and confidence interval construction for means and proportions, including standard asymptotic Wald and Wilson score intervals.

## 2. Mathematical Formulas
- **Sample Proportion ($p$) and Standard Error:**
  $$\hat{p} = \frac{x}{n}, \quad SE_{\hat{p}} = \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}$$

- **Wald Confidence Interval for Proportion:**
  $$\text{CI}_{\text{Wald}} = \hat{p} \pm z_{1-\alpha/2} \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}$$

- **Wilson Score Interval:**
  $$\tilde{p} = \frac{x + \frac{z^2}{2}}{n + z^2}, \quad \text{CI} = \frac{\hat{p} + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}$$

## 3. Implementation Summary
- Computes point estimates and analytical confidence intervals for proportions and means from scratch.
- Compares against `prop.test(..., correct = FALSE)`.
