# 10. Goodness-of-Fit, Contingency Tables, Non-parametric Tests & GLM

## 1. Overview
This module demonstrates categorical and non-parametric inferences alongside Generalized Linear Models (GLM):
- Pearson's Chi-Square Test for goodness-of-fit and independence in contingency tables.
- Wilcoxon Rank-Sum (Mann-Whitney U) non-parametric test.
- GLM Logistic Regression estimated via Iteratively Reweighted Least Squares (IRLS) / Newton-Raphson.

## 2. Mathematical Formulas
- **Chi-Square Test Statistic:**
  $$\chi^2 = \sum_{i=1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}}, \quad E_{ij} = \frac{R_i \cdot C_j}{N}$$

- **Wilcoxon Rank-Sum / Mann-Whitney $U$:**
  $$W = \sum_{i \in \text{Group 1}} R_i, \quad U = W - \frac{n_1(n_1 + 1)}{2}$$

- **Generalized Linear Model (Logistic Regression via Logit link):**
  $$\ln\left(\frac{p_i}{1 - p_i}\right) = X_i \beta, \quad p_i = \frac{1}{1 + e^{-X_i \beta}}$$
  Newton-Raphson update:
  $$\beta^{(t+1)} = \beta^{(t)} + (X^T W X)^{-1} X^T (y - p)$$
  where $W = \text{diag}(p_i(1 - p_i))$.

## 3. Implementation Summary
- Computes Chi-square statistics, expected frequency matrices, Wilcoxon rank sums, and Newton-Raphson GLM iterations purely from base arithmetic.
- Benchmarks against `chisq.test()`, `wilcox.test()`, and `glm(..., family = binomial)`.
