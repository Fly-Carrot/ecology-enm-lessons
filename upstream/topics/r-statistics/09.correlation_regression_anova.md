# 09. Correlation, Multiple Linear Regression, ANOVA, and Evaluation Metrics

## 1. Overview
This is a foundational econometric and statistical modeling module. It implements:
- Pearson correlation coefficient ($r$).
- Ordinary Least Squares (OLS) via normal equations $\hat{\beta} = (X^T X)^{-1} X^T y$.
- Comprehensive model metrics: $R^2$, Adjusted $R^2$, Within $R^2$ (fixed effects), RMSE, MAE, AIC, AICc.
- Distinctions between Dependent Variable ($Y$), Independent Variables ($X$), and Control Variables ($Z$).
- One-Way ANOVA table decomposition ($SSB, SSW, SST$).

## 2. Mathematical Formulas
- **OLS Parameter Vector:**
  $$\hat{\beta} = (X^T X)^{-1} X^T y$$

- **Goodness-of-Fit and Information Criteria:**
  $$R^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$
  $$\text{Adjusted } R^2 = 1 - \frac{SS_{\text{res}} / (n - k - 1)}{SS_{\text{tot}} / (n - 1)}$$
  $$\text{Within } R^2 = 1 - \frac{\sum_{i} \sum_{t} (y_{it} - \hat{y}_{it})^2}{\sum_{i} \sum_{t} (y_{it} - \bar{y}_i)^2}$$
  $$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}, \quad \text{MAE} = \frac{1}{n} \sum_{i=1}^n |y_i - \hat{y}_i|$$
  $$\text{AIC} = 2k - 2\ln(L), \quad \text{AICc} = \text{AIC} + \frac{2k(k+1)}{n - k - 1}$$

- **One-Way ANOVA:**
  $$SS_{\text{total}} = SS_{\text{between}} + SS_{\text{within}}, \quad F = \frac{MS_{\text{between}}}{MS_{\text{within}}} = \frac{SSB / (k-1)}{SSW / (n-k)}$$

## 3. Implementation Summary
- Solves linear systems via matrix inversion and vector products.
- Implements every single metric step-by-step without external packages.
- Benchmarks directly against R functions `cor()`, `lm()`, `summary.lm()`, `AIC()`, `aov()`.
