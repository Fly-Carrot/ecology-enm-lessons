# 04. Fundamental Concepts of Hypothesis Testing

## 1. Overview
This module breaks down the anatomy of statistical hypothesis testing: Null Hypothesis ($H_0$), Alternative Hypothesis ($H_1$), Type I Error ($lpha$), Type II Error ($eta$), Statistical Power ($1 - eta$), and exact $p$-value computation under the null distribution.

## 2. Mathematical Formulas
- **Type I Error Rate ($lpha$):**
  $$\alpha = P(\text{Reject } H_0 \mid H_0 \text{ is True})$$

- **Type II Error Rate ($\beta$) & Power ($1 - \beta$):**
  $$\beta = P(\text{Fail to Reject } H_0 \mid H_1 \text{ is True}), \quad \text{Power} = 1 - \beta$$

- **$p$-value (Two-tailed Z-test):**
  $$p\text{-value} = 2 \cdot \Phi(-|z_{\text{obs}}|) = 2 \cdot P(Z \ge |z_{\text{obs}}|)$$
  where $\Phi(z)$ is the standard normal cumulative distribution function.
